### Accelerated Introduction to Object-Oriented Programming in Java (Fall 2022 Semester, University of Utah)
This class was not a joke! I worked very hard for this class! I was also taking Engineering Economics, Linear Algebra for math majors, junior-level Statistics for math majors, and Strength of Materials this semester, and OOP was my last priority, so when I would run out of time to debug and such things, I would ask my dad for help to speed things along. ### R Studio Lab (Associated with Statistics course) (Fall 2022 Semester, University of Utah)
I didn't even realize that this statistics course included a computer lab when I signed up for it, and then there I was from 7-9 PM or something stupid, learning how to use R to analyze data sets! I had a weird time with R for a bit because I was learning Java at the same time and the whole declarative language thing threw me off, but eventually I realized Google is your friend for working with R and R is very powerful for analysis and building reports that input the correct numbers!

### Building Some Serious Excel Spreadsheets (March-December 2023)
I worked as a Structural Engineering Intern for a while, and my job was basically building complex excel spreadsheets to run calculations about geometry and other things for bridges and box culverts. Which is to say, I got very good at coding little boxes of excel spreadsheets to do cool stuff. I'm not totally sure why the entire field of Civil Engineering is running on excel and nobody has built better software for this (given that civil engineering involves calculus and excel isn't really built for that), but I did learn a lot from this experience!
